# Matriz A — Funcionalidades

Rutas relativas: Flutter `lib/features/` salvo indicación; Backend `backend/src/`. Pruebas indicadas por familia son unitarias/de widgets relacionadas, no E2E. El inventario completo permite localizar sus archivos.

Estado común **L/G**: IMPLEMENTADO LOCALMENTE y contenido en los HEAD publicados en GitHub comprobados durante el relevo. No implica DESPLEGADO, PROBADO EN INTEGRACIÓN con PostgreSQL ni PROBADO EN DISPOSITIVO REAL: esos tres estados no se acreditaron en esta ronda. PARCIAL indica huecos expresos; DEMO identifica ejecución ficticia; NO EXISTE se limita al contrato nuevo mencionado. No se afirma que producción carezca de algo sin inspeccionarla.

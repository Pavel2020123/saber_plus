# Orientación de carreras y universidades

La etapa 6E-E agrega `Más > Mi perfil > Carreras y universidades`. La pantalla orienta la exploración, pero no decide una vocación ni asegura admisión en una institución.

## Afinidad académica

SaberPlus relaciona los indicadores disponibles de las cinco materias con seis familias amplias de formación. El orden muestra afinidad académica, no una prueba vocacional. No utiliza género, edad, ubicación, capacidad de pago ni otros atributos personales para recomendar.

Las familias y ejemplos son contenido orientador general. No contienen puntajes mínimos, precios, fechas ni promesas de ingreso. Cuando solo existe evidencia de una materia, todas las sugerencias se presentan como opciones para explorar.

## Oferta oficial

El [SNIES del Ministerio de Educación](https://snies.mineducacion.gov.co/portal/EL-SNIES/A-quien-Aportamos/) informa que la ciudadanía puede consultar instituciones reconocidas y programas con registro calificado o acreditación, incluyendo lugar de ofrecimiento, matrícula y clasificación académica.

La aplicación abre externamente las consultas públicas oficiales:

- [Consulta de programas](https://hecaa.mineducacion.gov.co/consultaspublicas/programas)
- [Consulta de instituciones](https://hecaa.mineducacion.gov.co/consultaspublicas/ies)

SaberPlus no copia ese catálogo dentro de la aplicación porque la oferta, los registros y las acreditaciones pueden cambiar. Una integración futura deberá actualizarse desde el backend a partir de fuentes oficiales y conservar la fecha de actualización.

## Admisión

El puntaje proyectado no determina si una universidad admitirá al estudiante. Cada institución puede usar reglas, fechas, documentos, costos y pruebas adicionales diferentes. La pantalla obliga a verificar esos requisitos directamente antes de presentar una solicitud.
